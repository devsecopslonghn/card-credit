# Implement workflow

1. Read `AGENTS.md`, `.ai/` context and relevant package guidance.
2. Create or update a task record in `.agent/tasks/`.
3. Inspect only the relevant code, tests and existing scripts; write a short plan.
4. Implement the smallest change that satisfies the task.
5. Run the trusted gate, repair implementation failures (up to three normal attempts), and rerun it.
6. Record commands and results in `.agent/evidence/`, then update state and task status.
7. Finish only with PASS, genuine BLOCKED, or HUMAN_DECISION.
